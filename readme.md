# Word Counter App

A simple Word Counter Web App built using FastAPI.

## Features

- Count words
- Count characters
- Count characters without spaces
- Count sentences

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- Jinja2

## Run Project

Install requirements:

```bash
pip install -r requirements.txt

Start server:

uvicorn main:app --reload

Open in browser:

http://127.0.0.1:8000
